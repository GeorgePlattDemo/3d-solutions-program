## Keep the active record useful

Accepted work, explicit questions, results and decisions belong in the active record. Duplicate copies, obsolete implementation variants and working conversations do not become current merely because they can be recovered. Keep a concise disposition and source identity when an item is excluded; do not copy the entire rejected item into another active folder.

Run `python3 tools/check_program.py` to check this repository's local links, migration evidence and source identities. This is a documentary consistency check, not an application or machine-capability test.
